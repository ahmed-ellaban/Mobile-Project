# أبلة فهيدة 🍲

تطبيق موبايل (Android / iOS) باللغة العربية بالكامل، يربط أمهات مصر اللي بيطبخوا من بيوتهم بناس بتحب أكل البيت.
الهدف الأساسي: **زيادة دخل الأمهات** من موهبتهن في الطبخ، من غير ما يسيبوا ولادهم.

## الفكرة

- **الأم الشيف** تسجّل مطبخها، تضيف أكلها وأسعارها، وتحدّد إتاحة كل طبق يوم بيوم.
- **العميل** يتصفح المطابخ، يحجز الأكل، ويختار وقت استلام في نفس اليوم (أقرب موعد بعد ساعتين).
- **المحادثة** بين العميل والأم مباشرة للسؤال عن المكونات أو طلب تعديل.
- **الأثر** معروض للعميل في كل مكان: 85% من كل طلب يروح للأم، وقصص الأمهات بكلامهم، وأثر العميل الشخصي.

## التقنيات

- **Expo SDK 58** + **Expo Router** (التنقل بالملفات) + TypeScript.
- **react-native-reanimated 4** لكل الحركات (دخول العناصر، نبض القلب، علامة الصح، العدّادات، مؤشر الكتابة).
- **zustand** مع **AsyncStorage** لحفظ السلة والطلبات والمحادثات ومطبخ الأم محلياً.
- خط **Cairo** من Google Fonts، واتجاه **RTL** مفروض على الموبايل عبر `expo-localization` (`forcesRTL`) وعلى الويب عبر `dir="rtl"`.
- بدون سيرفر: البيانات تجريبية في `src/data/mock.ts`، وردود الأم في المحادثة وتقدّم حالة الطلب محاكاة محلياً.

## التشغيل

```bash
npm install
npx expo start
```

- افتح التطبيق في **Expo Go** على موبايلك (امسح QR)، أو اضغط `w` للويب.
- لتجربة الاتجاه RTL بشكل كامل على الموبايل استخدم **development build**:

```bash
npx expo run:android
```

> في Expo Go قد تحتاج لإعادة تشغيل التطبيق مرة بعد أول فتح حتى يُطبَّق الاتجاه من اليمين لليسار.
